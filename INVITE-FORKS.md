# Invite forks

**Steal this. Show your work.** Phase 2 start. Fork freely.

UniversalOS is a public blueprint. If a piece helps you build something honest, take it. You do not need permission.

---

## How to fork (ugly version)
1. Open [tiffmart/UniversalOS](https://github.com/tiffmart/UniversalOS).
2. Fork the repo (or copy one file — both count).
3. Fill **one** real piece using the [Receipts template](RECEIPTS-TEMPLATE.md).
4. Run the [Clarity engine notes](CLARITY-ENGINE-NOTES.md) checklist (match / partial / no match).
5. Keep closed bits labeled ([Transparency stub](TRANSPARENCY-STUB.md)).
6. Agree to the [Clarity Pledge](CLARITY-PLEDGE.md) if you remix or contribute.

Small loop. Public. Incomplete on purpose.

---

## What we want to see
- What you actually shipped (link + date)
- Promise → build → proof filled in
- Gaps labeled
- No puppets, no cosplay dashboards

What we do **not** need: a manifesto about forking.

2. Receipts > slogans.
