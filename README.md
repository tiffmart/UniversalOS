# UniversalOS

**The civic OS for people done with cosplay systems.**
Open-source clarity. No slogans. No puppets. Just receipts.

UniversalOS is a human-first, AI-aligned operating system for civic life: not finished software, but a public blueprint anyone can fork, remix, and pressure-test.

**If it doesn't match the promise, it isn't done.**

## What it is not
Not a phone or computer OS. Not a political party. Not a brand campaign. Not vibes without structure.

## How to use it
1. Read this README, the [Clarity Pledge](CLARITY-PLEDGE.md), the [Roadmap](ROADMAP.md), and the [Receipts template](RECEIPTS-TEMPLATE.md).
2. Fork what you need. How: [Invite forks](INVITE-FORKS.md).
3. Phase 1 foundation is complete. Phase 2 started: [invite forks](INVITE-FORKS.md).
4. Show your work with the receipts template: promise, build, proof.
