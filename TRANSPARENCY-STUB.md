## Default rules
1. **Open by default.** Closing something needs a written why, not a vibe.
2. **Label the closed.** Secrets without a label are cosplay transparency.
3. **Don't hide gaps behind dashboards.** Incomplete beats a pretty wall.
4. **Forkable.** Anyone can copy this stub without asking.
5. **Facts stay facts.** Don't alchemize data into slogans.

Pair with the [Receipts template](RECEIPTS-TEMPLATE.md): promise → build → proof still applies. This stub is the openness layer on top.
